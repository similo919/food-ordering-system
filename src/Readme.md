1. What is Spring Boot?

Spring Boot is a framework used to build Java applications quickly. It makes development easier by providing ready-made configurations and tools.

2. What is Maven?

Maven is a tool that helps manage Java projects. It downloads libraries, builds the project, and manages dependencies automatically.

3. What is the purpose of pom.xml?

The pom.xml file is used by Maven to manage the project. It contains information about dependencies, plugins, and project settings.

4. What is the purpose of application.properties?

The application.properties file is used to store application settings such as database connection details, server port numbers, and other configurations.

5. What does @SpringBootApplication do?

@SpringBootApplication is an annotation that marks the main class of a Spring Boot application. It enables auto-configuration and component scanning.

6. Why do developers use dependency management tools such as Maven?

Developers use Maven because it:

Downloads required libraries automatically.
Saves development time.
Makes project management easier.
Keeps dependencies organized.
7. What is a REST API?

A REST API is a way for applications to communicate with each other over the internet using HTTP requests such as GET, POST, PUT, and DELETE.

8. What is JSON?

JSON (JavaScript Object Notation) is a format used to store and exchange data. It is easy to read and is commonly used in REST APIs.

Example:

{
"id": 1,
"name": "Pizza"
}
9. What is Dependency Injection?

Dependency Injection is a concept where Spring automatically provides the objects a class needs instead of the class creating them itself. This makes code easier to manage and test.
